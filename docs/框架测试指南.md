# 框架测试指南

> 标准值源码：`tests/helpers/system-core.mjs` → `SYSTEM_CORE_BASELINE`（**`tests/` 已入库**；CI 跑 `pnpm test:coverage`，含覆盖率门禁）。仅统计 `core/system-Core/`，其他 core 与全仓库加载日志**不计入**达标线。

**文档串联**：[README.md](../README.md) → [docs/README.md](README.md) → [system-core.md](system-core.md) | 发布前：[代码审查清单.md](代码审查清单.md) + [文档审查清单.md](文档审查清单.md)

## 命令

入口：`tests/run.mjs`（`package.json` 各脚本调用此文件）。

| 命令 | 覆盖范围 | 说明 |
|------|------|------|
| `pnpm test` | unit | **仅** unit lane（默认快路径） |
| `pnpm test:fast` | unit + integration | 不起真实服务（CI 路径之一） |
| `pnpm test:integration` | integration | 进程内组装/mock/契约链路 |
| `pnpm test:e2e` | e2e | 真实启动 AgentRuntime |
| `pnpm test:all` | 三 lane 全量 | 本机全量回归用 |
| `pnpm test:smoke` | 跨 lane 精选子集 | 质量金字塔轻量门禁（**固定清单**，新增测试不自动入） |
| `pnpm test:coverage` | unit + integration | 跑一遍 fast 并对 13 个纯逻辑模块做行覆盖门禁（**CI 实际跑这个**） |
| `pnpm coverage:gate` | 同上 | 只跑覆盖率门禁，不跑 e2e |

### lane 语义（按「运行性质」分层，不是按被测对象）

目录即事实源：新增测试放进对应 lane 目录即自动入 lane，**无需改任何清单**。

| lane | 判据 | 现状 |
|------|------|------|
| `unit/` | 毫秒级纯逻辑，进程内直调 | 57 文件 |
| `integration/` | 进程内 mock/组装，无需真实端口/Redis/起服 | 15 文件 |
| `e2e/` | 真起 AgentRuntime / 全量 Loader 扫描 | 3 文件 |

覆盖率采集只覆盖 `unit + integration`（`e2e` 真起服，插桩数字无意义且拖慢门禁）。
lane 枚举的单一事实源是 `tests/lanes.mjs`，`run.mjs` 与 `coverage-gate.mjs` 共用。

`tests/` 结构：

```
tests/
  lanes.mjs            # lane 枚举单一事实源（run / coverage-gate 共用）
  run.mjs              # 唯一测试入口（各 test:* 脚本只调它）
  coverage-gate.mjs    # 行覆盖门禁（13 个纯逻辑模块）
  checks/              # 非 lane：docker/subservers 探针 + 质量门禁（lint-gate、unused-decls）
  helpers/             # bootstrap / harness-ai / system-core / test-server / www-alias
  unit/  integration/  e2e/   # 三个 lane
  perf/  baselines/    # 性能测试与基线
```

四道提交门禁（均在 CI 执行）：

| 命令 | 门禁 |
|------|------|
| `pnpm typecheck` | 全项目类型（tsc --noEmit） |
| `pnpm lint:gate` | ESLint 零问题 + 扫描范围下限（防 ignores 写宽成永远绿） |
| `pnpm lint:unused` | `src/` 无未使用 import/局部/参数（走 tsc 诊断，不自写正则） |
| `pnpm test:coverage` | fast 用例 + 13 模块覆盖率门禁 |

环境：**Node ≥ 26**、`XRK_TEST=1`；E2E 端口 `19000–19799`，就绪信号 `XRK_TEST_READY`。
测试引导（`tests/helpers/bootstrap.mjs`）：设置 `XRK_TEST=1`、stub `AgentRuntime`/`logger`，并 **import `dist/src/bootstrap-globals.js`**（源码 `src/bootstrap-globals.ts`；挂载 `PluginBase` / `msgSegment`，与生产 `src/agent-runtime.ts` 首行同源；勿直接 import 未编译的 `src/`，否则 PluginLoader 集成测会 `PluginBase is not defined`）。

Harness / AI 测入口：`tests/helpers/harness-ai.mjs` —— 用 `#infrastructure/*` / `#utils/*`（→ dist）稳定契约；勿手写 `../../dist/src/...`。类型面：`dist/src/infrastructure/ai-workflow/*.d.ts`。

### 编码与构建

- **编码**：`encoding-integrity` 扫 U+FFFD 与「中文被降级成连续问号」，只在字符串字面量（模板串先剥离 `${}` 插值）与中文注释里判定，整串问号（`|| '??'` 占位符）视为有意为之。范围含未提交的新文件。盲区：单字降级成单个 `?` 与 `?alt=sse` 同形。改 `src/` 后跑 `pnpm test:fast` 即覆盖。
- **构建**：`pnpm build` = `clean-dist` → `tsc` → `copy-runtime-assets`。必须先清空——`tsc` 不删旧产物，删掉的源文件会在 `dist/` 留下幽灵模块，测试 import 到已删实现仍通过（见 [coding-style.md](coding-style.md) §9.3）。**跑测试前先 build**，否则测的是上一次的 `dist/`。

## 质量基线

| 维度 | 实测 |
|------|------|
| 基准可审计 | 扩展 core 不稀释 11/7/18/4/4（见 `SYSTEM_CORE_BASELINE`） |
| CI 速度 | `test:fast` ~3 s、`test:coverage` ~5 s（Node 26） |
| 重依赖隔离 | `import` 后 `renderers.size === 0` |
| 测试离线 | `XRK_TEST=1` 跳过远程 MCP |
| 真启动 | E2E 子进程 `bot.run`，探活 12–125 ms |

复现：`pnpm test:all`（含 e2e）或 `pnpm test:coverage`（含门禁）。改标准值须同步 `tests/helpers/system-core.mjs` 与「标准值与实测」表。
