## 3. 安全

| 检查项 | 期望 |
|--------|------|
| `/api/*` | 默认鉴权；`systemAuth: false` 才公开 |
| 文件路径 | `InputValidator`（拒穿越；`isPathInside`） |
| SSRF | `assertUrlSafeForFetch` **默认拒私网**；仅 `allowPrivateNetwork` / `dangerouslyAllowPrivateNetwork` 显式 true 才放行（见 `ssrf-policy`） |
| 工具审批 | `security.approval` 默认 **false**：policy/toolScan 的 ask → 拒绝；开启后主人 `#批准`/`#拒绝`（`tool-approval`） |
| 可选外部扫描 | 发版/大改鉴权后可用 Strix（[security-strix.md](security-strix.md)）；勿把 PoC 入库 |

测：`input-validator` · `input-path-fuzz` · `security-checklist` · `tool-security` · `security-smoke-e2e`。

- [x] 安全项与文档期望一致（测文件仍存在于 `tests/unit/` 或 `tests/integration/`）
